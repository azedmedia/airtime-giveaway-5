# AirTime Drop — 5-slot airtime giveaway\n\n- ₦100 stated reward per accepted entry\n- MTN, Glo, Airtel network selection\n- Nigerian phone-number format validation\n- Five unique phone numbers maximum, enforced server-side\n- Telegram notification for accepted entries; manual airtime top-up only\n\n## Setup\nRequires Node.js 20+. Run `npm install`, copy `.env.example` to `.env`, set `BOT_TOKEN` and `ADMIN_CHAT_ID`, then run `npm start` and open `http://localhost:3000`. Never publish `.env` or the bot token to GitHub.\n\nDeploy to a Node.js host with persistent storage. SQLite lives in `data/airtime.sqlite`; attach a persistent disk to `data/` or entries may be lost after redeploy. Tell entrants their phone number is sent privately to the organizer for manual top-up. Never request OTPs, PINs, passwords, or banking details.
